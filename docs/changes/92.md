- **`basal-bench` measures what `basal-serve` serves** (`basal-bench`, `basal-bench --order-check`): the prompts follow
  the `layout` of the model's `basal.json` (they were always canonical), a model with `option_isolation` gets its
  option blocks instead of stopping on an assertion, and `--modes nvfp4` reads `NVFP4_AMAX.json` from the model folder
  instead of refusing. The throughput pass is also warmed on all eight chunks of 16 questions, not the first one, so
  a backend that compiles per shape (`--modes tpu`) no longer counts compilation in `dec_s`. Contributed by
  Rafal Wiktorowicz (NovaraX), [#92](https://github.com/rkinas/basal/pull/92).
